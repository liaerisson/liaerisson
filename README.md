## Selected Work

### 📈 C++ Limit Order Book & Matching Engine

A limit order book and matching engine implementing price-time priority, FIFO order queues, direct order lookup, cancellation, and best-price matching.

`C++` · `Data Structures` · `Algorithms` · `CMake` · `Catch2`

### 📄 [Paper Reviewer](https://github.com/liaerisson/Paper-Reviewer-Public)

A research-oriented AI agent built with Amazon Bedrock AgentCore and a retrieval knowledge base. It analyzes academic papers and produces structured summaries and glossaries while distinguishing reported evidence from inference and speculation.

`Python` · `Amazon Bedrock` · `AgentCore` · `Information Retrieval`

### 🔎 [Java Document Search Engine](https://github.com/liaerisson/FileIngestor)

A Java search engine built around a custom inverted index and query-processing pipeline. It supports ranked keyword search through both a command-line interface and Spring Boot REST API, with validation, HTTP error handling, and web-layer testing.

`Java` · `Spring Boot` · `REST APIs` · `Inverted Index` · `JUnit`

### 🗃️ Summer Industry Work

As a Product Analyst Intern at **CHEQ**, I worked on knowledge bases and SQL retrieval for a client-facing AI agent spanning three internal databases. My work involved mapping undocumented database relationships, resolving conflicting business definitions, writing retrieval logic, and validating agent responses through an MCP proof of concept.

One of these databases continuously recorded more than 1B daily site interactions across 15,000+ customers.
